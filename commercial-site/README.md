# 机场套餐商业比较静态站（源码）

## 作用
本目录是带佣金邀请链接的独立静态站源码，首页带周期成本计算器，并包含10个品牌各自的 `brands/<slug>/index.html` 页面。页面可直接被自有静态托管部署，当前未配置生产域名或上线。

## 重要边界
- 此目录 **不纳入** 现有 GitHub Pages 演示版的发布工作流；GitHub Pages 不能作为主要用于商业交易的免费主机。
- 已验证的 GitHub Pages 计算器、Google/Bing 验证码和现有 Actions 均不改动。
- 所有本地 CSS/JS；没有外部字体、统计脚本、CDN、外部数据接口。
- HTML 中仅使用10条白名单推广目标，所有商业按钮都标注 `rel="sponsored nofollow noopener noreferrer"`。
- 参考价格源于历史记录，**不等于当期售价**，不存在测速或网络质量保证。
- 本源码采用乌龟云最近一次经过两站生产核验的既有邀请码 `rdf0Vi1H`。其他资料曾出现不同邀请码 `Ld9SHVnT`，没有对联盟后台完成最终核实前，不能静默替换。
- 不使用任何第三方商家普通官网作为链接。

## 使用
将 `commercial-site/` 作为静态站发布根目录（例如 Cloudflare Pages 连接本 GitHub 仓库，并指定此目录为输出；实际部署需另行授权并检查 URL）。确认真正的域名后再添加对应 self canonical 和 Sitemap，不要猜测域名。请先人工复核商家链接和网站安全状态。

## 验收
共有11个 HTML 页面（首页+10品牌），10个唯一站外邀请目标。主站和此商业版不得通过反向代理将用户隐藏跳转到其他不在白名单的站点。
