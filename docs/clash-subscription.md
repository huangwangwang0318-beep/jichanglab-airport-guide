# Clash 订阅导入与更新排查

订阅 URL 指向可重新获取的配置内容；本地配置文件只是一次保存的内容。客户端是否能导入，取决于其内核、版本、配置格式及商家给出的具体说明。“支持 Clash”不足以证明任意 Windows、macOS、Android 或 iOS 客户端都兼容。Mihomo 官方文档把 HTTP、文件和内联的代理提供者分开，并定义了更新间隔；第三方客户端的功能仍由各自项目维护。

## 导入前检查

1. 从商家账户页确认链接的用途与格式，只在自己信任的客户端中输入。订阅 URL 往往含有账户令牌，应视为敏感资料。
2. 查看客户端说明中支持的配置类型和内核版本。若商家提供多个格式，选明确匹配的一项，不要仅凭文件名猜测。
3. 核对链接复制是否完整。被聊天软件截断、附加标点、过期或已撤销的链接都可能失败。
4. 如果采用本地文件，确认文件内容是客户端可解析的配置，而非登录页、错误页或纯文本提示。

## 按错误位置排查

| 症状 | 检查顺序 |
| --- | --- |
| 无法下载 | 链接是否完整、设备网络是否可达、商家是否更换地址、是否提示认证失败 |
| 下载成功但解析失败 | 返回内容格式、客户端版本、是否误用其他内核的订阅格式 |
| 首次导入成功但无法更新 | 客户端更新功能与日志、链接是否过期、商家侧是否暂停服务 |
| 节点显示但连接失败 | 套餐是否到期或超额、节点是否维护、客户端系统代理与 DNS 设置 |

Windows 和 macOS 上的客户端可能使用不同内核或打包版本；移动端可能受系统网络权限与应用分发限制。排查时记录**不含令牌**的错误信息、系统和客户端版本、发生时间，联系商家支持。不要在公开 Issue、截图、日志或配置样本里贴真实订阅地址。
