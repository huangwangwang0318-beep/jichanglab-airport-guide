# 计算方法与适用边界

版本 1.1，2026-11-11。所有值为输入模拟，**不是实时套餐报价**。

## 输入

- 使用月数 `M`：1–36，按整月估算。现实的自然月天数、闰年、退款不参与计算。
- 每月使用 `U` GB：用户实际使用量。节点倍率 `F` 为该套餐计费倍数，套餐内计费需求为 `U × F`。
- 同时设备数 `D`：若填写了设备上限 `L`，则必须 `D <= L`；未知时仅警告。
- 付费金额 `P`：一次真实扣款，最多两位小数（内部按整数分计算）。

## 周期付费

周期 `C` 取 1、3、6、12 个月。付款次数 `N = ceil(M/C)`，实际现金支出 `N × P`，预付但未使用的月份为 `N × C - M`。

- **每月重置额度**：每一个使用月必须满足 `U × F <= quotaGB`。
- **整个付款周期固定额度**：每一个实际使用的周期窗口中，需要满足 `U × F × activeMonths <= quotaGB`。最后一个周期的 `activeMonths` 可能小于 `C`，但仍按完整周期付款。
- **重置规则尚未核实**：仍可按付款周期估算现金支出，但不判断流量是否够用，也不提供名义流量成本或最终选购结论。
- 不自动假设超额加购、按次退款、退款比例、自动续费成功、流量结转、加购折扣。

## 一次性流量

有效期 `V`（月）必须已知，否则无法可靠计算。将 `M` 划分为不超过 `V` 个月的窗口。每个窗口内 `packs = ceil(activeMonths × U × F / quotaGB)`，总付款次数等于所有窗口所需包数之和。

**关键假设**：可以同时购买多个包，且有效期起点可与下一使用窗口对齐；窗口内未用额度不能跨窗口结转。现实有效期如果按“自然日”计费，或在购买后即刻开始，有效期与实际需求可能不吻合，需要以真实条款调整，模型不支持具体到天的到期预测。

## 结果解释

- **预计总支出**：输入条件成立时按完整周期/流量包付款，不是实际账单。
- **每月均摊现金支出**：总支出除以计划使用月数；不代表可以按月分期支付。
- **名义每已购 1GB 成本**：总支出除以已购额度。月度重置按已付款周期覆盖的总月份乘以月额度；固定周期按付款次数乘以周期额度；一次性按购买包数乘以每包额度。它反映购买的标称容量，未用或过期的流量仍计入分母，不代表真实使用成本。
- **每实际消耗 1GB 成本**：总支出除以 `U × M`；与按节点倍率计费 GB 的价格不同。若额度或设备条件不满足，不给出有误导性的单位成本结论。
- **未使用额度**：估计值，不代表退款、留存或下期可使用。
- **不比较速度、品牌稳定性、客服与退款**，这些都无法靠输入金额验证。
